# Fractol

**Fractol** is a graphical fractal explorer written in **C** using the **MiniLibX** graphics library. It renders and displays fractal sets like **Mandelbrot** and **Julia** on the screen and allows you to interact with them using keyboard and mouse controls.

This project is based on the classic *fract-ol* fractal renderer assignment from the 42 School curriculum — a great way to learn about complex numbers, iterative fractal algorithms, low-level graphics, and event handling in C.

---

## 🧠 What Are Fractals?

Fractals are mathematical sets that exhibit **self-similar patterns** at every scale. Famous examples include the **Mandelbrot Set** and **Julia Sets**, which are generated by iterating simple mathematical equations for each pixel on the screen and coloring each pixel based on how quickly the sequence diverges. :contentReference[oaicite:2]{index=2}

## 🚀 Features

- 🎨 Render beautiful fractals in real time  
- 🌀 Navigate and explore fractals with interactive controls  
- 📌 Currently supports core-set fractals such as:  
  - Mandelbrot  
  - Julia  
  *(you can extend with Burning Ship, Tricorn, etc.)*  
- 💡 Simple command-line usage  
- 📏 View zooming and panning via mouse + keyboard

> **Note:** Library files like `libmlx.a` are included for convenience (look in the repository). See the **bonus/** branch for potential enhancements.

## ⚙️ Requirements

To build and run this project, you need:

- A **C compiler** (e.g., `gcc`)
- **Make**  
- **MiniLibX** (included or installed separately)
- Standard C libraries (`stdlib.h`, `math.h`, etc.)

---

## 📦 Installation & Build

1. **Clone the repository**

   ```bash
   git clone https://github.com/mohos26/fractol.git
   cd fractol


2. **Compile the program**

   ```bash
   make
   ```

3. **Run the fractal viewer**

   ```bash
   ./fractol <fractal_type>
   ```

---

## ▶️ Usage

Example commands to render different fractals:

* **Mandelbrot**

  ```bash
  ./fractol mandelbrot
  ```

* **Julia Set**

  ```bash
  ./fractol julia
  ```

> For Julia, additional parameters may be accepted depending on your implementation (e.g., `./fractol julia -0.7 0.27015`).

## 🧩 How It Works (High-Level)

1. Each screen pixel is mapped to a point in the complex plane.
2. Based on the fractal type, a mathematical equation is iterated.
3. The iteration counts determine pixel color (escape time algorithm).
4. Zooming and moving update the range of complex values. ([GitHub][2])
